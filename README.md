# Système embarqué IoT

## Présentation

Projet de conception d'un système embarqué capable d'acquérir
des données provenant de capteurs et de les transmettre à distance.

## Technologies

- Microcontrôleur
- C/C++
- Capteurs
- Communication
- IoT

## Fonctionnement

Capteurs
→ Microcontrôleur
→ Traitement
→ Communication
→ Exploitation des données

## Objectifs

- Acquérir des mesures
- Traiter les données
- Communiquer les informations
- Gérer les erreurs
- Valider le fonctionnement
